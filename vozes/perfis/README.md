# Adicione perfis de voz aqui

Copie um perfil **Kokoro-82M v1.0 brasileiro**, com nome novo `pf_nome.bin` ou `pm_nome.bin`. Recarregue a extensão e use **Atualizar vozes** no painel. Não é preciso editar código no Chrome 122+.

MP3, WAV e modelos de outros motores não são perfis compatíveis. Leia `../README.md` para a estrutura, formatos, fontes e limitações.
